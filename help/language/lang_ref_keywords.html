Keywords 

The following keywords are built into Blitz, and may not be used as identifiers (variables, function names, labels, etc.).

Core keywords

The classic Blitz3D keywords, supported unchanged for drop-in compatibility:


After, And, Before, Case, Const, Data, Default, Delete, Dim, Each, Else, ElseIf, End, EndIf, Exit, False, Field, First, Float, For, Forever, Function, Global, Gosub, Goto, If, Insert, Int, Last, Local, Mod, New, Next, Not, Null, Or, Pi, Read, Repeat, Restore, Return, Sar, Select, Shl, Shr, Step, Str, Then, To, True, Type, Until, Wend, While, Xor, Include

BlitzForge additions

BlitzForge reserves these additional words for its modern language extensions. See the Modern Features page for what each does. Note that these words are reserved in all programs, so legacy code that used one of them (for example test or release) as a variable or function name will need that identifier renamed:


Assert, Continue, DisableGC, EnableGC, End Method, End Test, Method, NoTrace, Ptr, Recast, Reference, Release, Strict, Test

Some further extensions are recognised in context rather than as standalone reserved words — among them Extends-style type inheritance (Type Child.Parent), the function-pointer sigil @, and the runtime constructs Async, Await, Poll, AsyncThen, Throw and TryCatch. These are also covered on the Modern Features page.
