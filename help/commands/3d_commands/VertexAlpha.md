# VertexAlpha# ( surface,index )

# Parameters

  -----------------------------------------------------------------------
  surface - surface handle\
  index - index of vertex

  -----------------------------------------------------------------------

# Description

  -----------------------------------------------------------------------
  Returns the alpha component of a vertices color, set using
  [VertexColor](../3d_commands/VertexColor.htm){.small}\
  \
  See also: [VertexRed](VertexRed.htm){.small},
  [VertexGreen](VertexGreen.htm){.small},
  [VertexBlue](VertexBlue.htm){.small},
  [VertexColor](VertexColor.htm){.small}.

  -----------------------------------------------------------------------
