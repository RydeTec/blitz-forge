# EntityName\$ ( entity )

# Parameters

  ------------------------
  entity - entity handle
  ------------------------

# Description

  -----------------------------------------------------------------------
  Returns the name of an entity. An entity\'s name may be set in a
  modelling program, or manually set using NameEntity.\
  \
  See also: [NameEntity](NameEntity.htm){.small}.

  -----------------------------------------------------------------------
