# BrushBlend brush,blend

# Parameters

  -----------------------------------------------------------------------
  brush - brush handle\
  blend -\
  1: alpha (default)\
  2: multiply\
  3: add

  -----------------------------------------------------------------------

# Description

  -------------------------------------
  Sets the blending mode for a brush.
