# UpdateNormals mesh

# Parameters

  --------------------
  mesh - mesh handle
  --------------------

# Description

  --------------------------------------------------------------------------------------------------------------------------------------------------
  Recalculates all normals in a mesh. This is necessary for correct lighting if you have not set surface normals using \'VertexNormals\' commands.
  --------------------------------------------------------------------------------------------------------------------------------------------------
