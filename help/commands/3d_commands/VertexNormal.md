# VertexNormal surface,index,nx#,ny#,nz#

# Parameters

  -----------------------------------------------------------------------
  surface - surface handle\
  index - index of vertex\
  nx# - normal x of vertex\
  ny# - normal y of vertex\
  nz# - normal z of vertex

  -----------------------------------------------------------------------

# Description

  ----------------------------------------
  Sets the normal of an existing vertex.
