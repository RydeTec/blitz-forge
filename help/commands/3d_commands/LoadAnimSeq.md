# LoadAnimSeq ( entity,filename\$ )

# Parameters

  -----------------------------------------------------------------------
  entity - entity handle\
  filename\$ - filename of animated 3D object

  -----------------------------------------------------------------------

# Description

  -----------------------------------------------------------------------
  Appends an animation sequence from a file to an entity.\
  \
  Returns the animation sequence number added.

  -----------------------------------------------------------------------
