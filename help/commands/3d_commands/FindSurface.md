# FindSurface ( mesh,brush)

# Parameters

  -----------------------------------------------------------------------
  mesh - mesh handle\
  brush - brush handle

  -----------------------------------------------------------------------

# Description

  -----------------------------------------------------------------------
  Attempts to find a surface attached to the specified mesh and created
  with the specified brush. Returns the surface handle if found or 0 if
  not.\
  \
  See also: CountSurfaces, GetSurface.

  -----------------------------------------------------------------------
