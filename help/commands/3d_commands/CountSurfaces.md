# CountSurfaces ( mesh )

# Parameters

  --------------------
  mesh - mesh handle
  --------------------

# Description

  -----------------------------------------------------------------------
  Returns the number of surfaces in a mesh.\
  \
  Surfaces are sections of mesh. A mesh may contain only one section, or
  very many.\
  \
  See also: GetSurface.

  -----------------------------------------------------------------------
