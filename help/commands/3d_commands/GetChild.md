# GetChild (entity,index)

# Parameters

  -----------------------------------------------------------------------
  entity - entity handle\
  index - index of child entity. Should be in the range
  1\...CountChildren( entity ) inclusive.

  -----------------------------------------------------------------------

# Description

  -------------------------------
  Returns a child of an entity.
  -------------------------------
