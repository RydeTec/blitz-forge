# TriangleVertex ( surface,triangle_index,corner )

# Parameters

  -----------------------------------------------------------------------
  surface - surface handle\
  triangle_index - triangle index\
  corner - corner of triangle. Should be 0, 1 or 2.

  -----------------------------------------------------------------------

# Description

  ------------------------------------------
  Returns the vertex of a triangle corner.
  ------------------------------------------
