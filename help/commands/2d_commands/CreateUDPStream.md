# CreateUDPStream( \[port\] )

# Parameters

  -------------------------------
  port (optional) - port number
  -------------------------------

# Description

  -----------------------------------------------------------------------------------------------------------------------------
  If no port is specified, a free port will be allocated and you can then use UDPStreamPort() to find out the allocated port.
  -----------------------------------------------------------------------------------------------------------------------------
