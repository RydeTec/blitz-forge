# GammaGreen ( green )

# Parameters

  -----------------------------------------------------------
  green - an integer color component in the range 0 to 255.
  -----------------------------------------------------------

# Description

  ---------------------------------------------------------------------------------------------------------
  Returns the current output green component of the gamma tables for the specified input green component.
  ---------------------------------------------------------------------------------------------------------
