# UDPStreamIP( udp_stream )

# Parameters

  --------------------------------
  udp_stream - UDP stream handle
  --------------------------------

# Description

  -----------------------------------------------------------------------------------------------
  Returns the integer IP address of the specified udp_stream. Currently, this always returns 0.
  -----------------------------------------------------------------------------------------------
