# To

# Parameters

  -------------
  See example
  -------------

# Description

  -----------------------------------------------------------------------
  Use the TO command to tell your FOR \... NEXT loop which numbers the
  variable should be assign to during the loop. If you count down instead
  of up, you must use a negative STEP value. The values must be integer
  values. See example.\
  \
  See also: [For](For.htm){.small}, [To](To.htm){.small},
  [Step](Step.htm){.small}, [Each](Each.htm){.small},
  [Next](Next.htm){.small}, [Exit](Exit.htm){.small},
  [While](While.htm){.small}, [Repeat](Repeat.htm){.small}.

  -----------------------------------------------------------------------

# [Example](../2d_examples/To.bb)

  -----------------------------------------------------------------------
  ; Print numbers 10 to 1\
  \
  For t = 10 to 1 Step -1\
  Print t\
  Next

  -----------------------------------------------------------------------
