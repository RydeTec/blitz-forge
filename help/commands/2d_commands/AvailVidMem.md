# AvailVidMem()

# Parameters

  -------
  None.
  -------

# Description

  --------------------------------------------------------------------------------------------------------------------
  This command will return the total bytes of available free video memory. Use this to keep track of your resources!
  --------------------------------------------------------------------------------------------------------------------

# [Example](../2d_examples/AvailVidMem.bb)

  -----------------------------------------------------------------------
  Print \"Your available video memory is: \" + AvailVidMem()\

  -----------------------------------------------------------------------
