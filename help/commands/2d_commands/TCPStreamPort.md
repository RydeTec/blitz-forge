# TCPStreamPort( tcp_stream )

# Parameters

  --------------------------------
  tcp_stream - TCP stream handle
  --------------------------------

# Description

  ---------------------------------------------------------------------------------------------------------------------
  Returns the port number of the specified TCP stream. The port number returned is always that of the client machine.
  ---------------------------------------------------------------------------------------------------------------------
