# ScanLine()

# Parameters

  -------
  None.
  -------

# Description

  -----------------------------------------------------------------------
  If for some reason you need to know the current scanline location of
  the drawing system, here is how you get it.\
  \
  See also: [VWait](VWait.htm){.small}, [Flip](Flip.htm){.small}.

  -----------------------------------------------------------------------

# [Example](../2d_examples/ScanLine.bb)

  -----------------------------------------------------------------------
  ; ScanLine() Example\
  \
  While Not KeyHit(1)\
  Print ScanLine()\
  Wend

  -----------------------------------------------------------------------
