# End Type

# Parameters

  ------
  None
  ------

# Description

  -----------------------------------------------------------------------
  If you haven\'t read up on the TYPE command, you might want to do so
  before continuing.\
  \
  After assigning all the Field variables in your Type object, use this
  to finish the creation of the Type.

  -----------------------------------------------------------------------

# [Example](../2d_examples/End){type.bb=""}

  -----------------------------------------------------------------------
  ; Define the CHAIR Type\
  \
  Type CHAIR\
  Field X\
  Field Y\
  Field HEIGHT\
  End Type\

  -----------------------------------------------------------------------
