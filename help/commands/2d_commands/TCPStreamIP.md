# TCPStreamIP( tcp_stream )

# Parameters

  --------------------------------
  tcp_stream - TCP stream handle
  --------------------------------

# Description

  ------------------------------------------------------------------------------------------------------------------------
  Returns the integer IP address of the specified tcp_stream. The address returned is always that of the client machine.
  ------------------------------------------------------------------------------------------------------------------------
