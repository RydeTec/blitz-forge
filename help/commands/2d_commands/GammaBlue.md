# GammaBlue ( blue )

# Parameters

  ----------------------------------------------------------
  blue - an integer color component in the range 0 to 255.
  ----------------------------------------------------------

# Description

  -------------------------------------------------------------------------------------------------------
  Returns the current output blue component of the gamma tables for the specified input blue component.
  -------------------------------------------------------------------------------------------------------
