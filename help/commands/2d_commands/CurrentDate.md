# CurrentDate\$()

# Parameters

  ------
  None
  ------

# Description

  -------------------------------------------------------------------------
  Returns the current date in the format: DD MON YYYY (i.e. 10 DEC 2000).
  -------------------------------------------------------------------------

# [Example](../2d_examples/CurrentDate.bb)

  -----------------------------------------------------------------------
  ; Print the current date to the screen\
  \
  Print \"The date is:\" + CurrentDate\$()\

  -----------------------------------------------------------------------
