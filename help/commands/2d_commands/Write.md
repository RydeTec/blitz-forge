# Write string\$

# Parameters

  -------------------------------------
  string\$ - string variable or value
  -------------------------------------

# Description

  -----------------------------------------------------------------------
  Writes a string to the front buffer (i.e. the screen), but doesn\'t
  then start a new line (unlike Print).\
  \
  See also: Print.

  -----------------------------------------------------------------------

# [Example](../2d_examples/Write.bb)

  -----------------------------------------------------------------------
  ; Write Example\
  ; \-\-\-\-\-\-\-\-\-\-\-\--\
  \
  Write \"Blitz \"\
  Write \"Basic\"\

  -----------------------------------------------------------------------
