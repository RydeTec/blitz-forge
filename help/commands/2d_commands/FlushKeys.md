# FlushKeys

# Parameters

  -------
  None.
  -------

# Description

  -------------------------------------------------------------------------------------------------------------------------
  This command \'resets\' or \'empties out\' the queue holding the keyboard inputs. Can\'t make it much easier than that.
  -------------------------------------------------------------------------------------------------------------------------

# [Example](../2d_examples/FlushKeys.bb)

  -----------------------------------------------------------------------
  ; clear all keystrokes from the queue\
  FlushKeys\

  -----------------------------------------------------------------------
